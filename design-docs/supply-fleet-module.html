The "tick" re-render conventionSeveral seeds in this app (FLEET_SEED, ASSIGNMENT_QUEUE_SEED, ORDERS_SEED) are mutated in place by their own action functions rather than replaced via setState. Pages force a re-render after calling one with a dummy const [, setTick] = useState(0) counter. Match this if you're extending one of these seeds — don't switch it to immutable state half-way through a file.

04 If you're building here

  • New compliance document type? Extend COMPLIANCE_LABEL/COMPLIANCE_BADGE in data/fleet.js, matching the existing valid/expiring/expired shape.
  • A manifest arrives here from Trip Module's Routing Simulator — don't build a second manifest-creation path in this module.
  • Confirming an assignment is the hand-off point back to Trip Module (createTripFromAssignment()) — any new assignment UI should call through the same function, not construct a trip object directly.

How to use this library

  1. Read the Design System once before writing any new screen — it's the token file the whole app already follows, just pulled out and shown.
  2. Open your module's reference before adding a screen — it tells you which shared data exports to import instead of re-deriving state locally, and which existing pattern (repeatable row, suggest-then-confirm, tick-based re-render) your new feature probably matches.
  3. Check the Standardization notes at the bottom of the Design System before introducing a new button/badge/card variant — there's a good chance one already exists, just inconsistently applied.
  4. These files live in design-docs/ at the project root and are not imported by the app — edit them directly, they don't need a build step. Open index.html locally or serve the folder to browse.

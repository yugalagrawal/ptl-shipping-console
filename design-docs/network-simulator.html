Network Simulator

A "what if" workbench — two calculators that let ops and sales explore cost and routing without touching a real order or client.

Sidebar group: Network Simulator Base route: /network-simulator/* Files: src/pages/network/*.jsx

01 Overview

The two screens are not the same kind of tool, and it's worth being precise about which is which before extending either.

02 Screens

Route & Cost Simulator/network-simulator/route-cost

Illustrative only — hub-and-spoke routing levers (origin, hub chain, vehicle type, service level) rendered against hardcoded sample stats and a cost breakdown chart. Nothing on this screen is computed live; it's a concept of what a real network simulation would show once a cost-per-trip and utilization model exist.

hardcoded sample datacost breakdown bar
Freight Calculator/network-simulator/freight-calculator

Fully real — reuses the exact same pricing engine as Create Order's live preview (computeOrderPricing() in data/pricing.js), just against a synthetic {'{'} tier, matrix, charges {'}'} instead of a real client. Lets sales quote a lane before a client is even onboarded.

real pricing enginesynthetic client object
Don't confuse the twoIf a stakeholder asks for a network-level enhancement, check which screen they mean — "make the simulator more accurate" almost certainly means Route & Cost Simulator (still illustrative), while "the freight calculator is wrong" is a real pricing-engine bug shared with Create Order.

03 If you're building here

  • Making Route & Cost Simulator real requires a cost-per-trip / manifest-utilization model that doesn't exist yet — see Trip Module and Supply & Fleet Module for where that data would come from.
  • Any pricing change belongs in data/pricing.js so Freight Calculator and Create Order stay identical — never fork the freight math into this page.
